# Context Optimiser — Claude plugin

Claude Code plugin shell for `@yavdaanalytics/context-optimiser`.

## What this package includes

- **Skill** (`skills/context-optimiser/SKILL.md`) — when and how to use context compaction / rotation
- **MCP server** (`mcp.json`) — `npx -y @yavdaanalytics/context-optimiser`

## Install

Via the Yavda marketplace (`yavda-tools`), then run setup once:

```sh
npx -y -p @yavdaanalytics/context-optimiser context-optimiser-setup
```

Local development:

```sh
node bin/setup.js --local
```
